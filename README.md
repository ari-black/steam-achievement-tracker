### Overview

*Steam Achievement Tracker* is an unfinished full-stack web application meant to allow users to track their achievements on Steam, on hiatus.

Originally intended to give me more full-stack experience using frameworks I wasn't very familiar with, 
this project was paused indefinitely so I could focus on the job I subsequently started, allowing me to work on full-stack development full-time :).

If I find more time in the future for independent development, it would be fun to continue this project once again using my new skills and knowledge.
